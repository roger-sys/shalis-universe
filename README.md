# Shaki's Universe ✨

A magical, interactive, and positive single-page Progressive Web App (PWA) made especially for Shaki.

## Features
- 🌞 **Daily Motivation**: Random uplifting quotes with interactive flip animations.
- 😊 **Mood Booster**: Tailored cosmic notes based on how she is feeling.
- 🎡 **Fun Wheel**: A decision-making wheel to select fun daily activities.
- 👑 **Compliment Generator**: Infinite sweet words with floating heart particles.
- 🎯 **Daily Challenges**: Complete challenges to earn stars!
- 🏆 **Achievement Board**: Track star count progress and rank up.
- 🌈 **Dream Wall**: Pin sticky notes of goals and dreams.
- 💌 **Secret Star Map**: Tap scattered stars to reveal hidden sweet messages.
- 🧘‍♀️ **Relaxation Corner**: Deep breathing bubbles to help relax and focus.
- 🎮 **Arcade Games**: Rock-Paper-Scissors, Number Guessing, and Click-the-Star.
- 🌙 **Night Mode**: Easily toggle between pastel day and starry night mode.

## Installation & Offline Access
Since this is a PWA, it can be installed on iOS and Android devices:
1. Open the hosted GitHub Pages link in your mobile browser.
2. Tap **Share** (iOS Safari) or **Settings** (Android Chrome) and select **"Add to Home Screen"**.
3. Launch it from your home screen anytime, even offline!
